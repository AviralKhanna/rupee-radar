# Rupee Radar

Public portfolio dashboard demo built with Next.js and React. Sample prices are illustrative. CSV imports stay in the browser.

## Run

```sh
npm ci
npm run dev
```

## Deploy

Vercel uses the Next.js preset. No credentials are needed for the public demo. The Groww API is disabled by default; never enable a shared personal brokerage account on a public deployment.
